---

Pedro Pathing is a **path following library** developed to revolutionize autonomous navigation in robotics.

Pedro Pathing uses GVF-based feedforward + feedback control and a time-independent formulation directly accounting for loop time-based lag, and generates brake profile based on identified system dynamics for faster and more accurate autonomous routines.

Using Pedro Pathing for your autonomous routines allows for:

- **Faster path execution:** Vector prioritization is optimized for speed and accuracy.
- **Correction for disturbances:** Pedro corrects for disturbances and swiftly returns to the path after deviations.
- **Creating paths on-the-fly:** Pedro Pathing allows for dynamic path creation, enabling your robot to adapt pathing in real time.
- **Easily make complex paths:** Pedro Pathing's Visualizer allows for quick and easy path creation for both simple and complex Bézier curves. 

No matter how good your team is, Pedro Pathing can give you the tools necessary to create high-quality, fast, consistent autos.
