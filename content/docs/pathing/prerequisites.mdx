---
title: Prerequisites
description: Prerequisites for using Pedro Pathing
---

Before starting to use Pedro Pathing you should make sure you have a few thing ready.

### Holonomic drive

For Pedro Pathing to work you need to make sure you have some kind of Holonomic drivetrain. By default Pedro Pathing supports Mecanum and Swerve but any Holonomic drivetrain could be used.

### Localization

The Robot needs some way to know where it is, for that some kind of Localization is a must. By default Pedro Pathing supports: **Pinpoint**, **dead-wheel**, **OctoQuad** and **OTOS**. Any form of localization would work if you make a localizer for it. 

### Programming platform

For Pedro Pathing you **must** use **Android studio**. Pedro Pathing does not work with OnBot Java or Blocks.

Once you made sure you completed all of those you can go right ahead to installing Pedro Pathing [here](/docs/pathing/installation).
