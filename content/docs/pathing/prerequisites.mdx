title: Prerequisites
description: Prerequisites for using Pedro Pathing
---

Before using Pedro Pathing, you have to make sure you have the following prerequisites:

### Holonomic Drive

You have some kind of Holonomic drivetrain.

By default, Pedro Pathing supports **Mecanum** and **Swerve** but any Holonomic drivetrain could be used.

### Localization

The robot needs a way to know where it is on the field.

By default, Pedro Pathing supports: **Pinpoint**, **OctoQuad**, **OTOS**, **Two Wheel**, **Three Wheel**, and **Three Wheel IMU**.

### Programming Platform

To use Pedro Pathing, you **must** use **Android Studio**. Pedro Pathing does **not** work with OnBot Java or Blocks.

## Next Steps

Once you made sure you completed all of those, you can [proceed to installation](/docs/pathing/installation).
