---
title: Prerequisites
description: Prerequisites for using Pedro Pathing
---

Before starting to use Pedro Pathing you should make sure you have a few things ready.

### Holonomic Drive

For Pedro Pathing to work you need to make sure you have some kind of Holonomic drivetrain. By default, Pedro Pathing supports **Mecanum** and **Swerve** but any Holonomic drivetrain could be used.

### Localization

The robot needs a way to know where it is on the field. Because of this, reliable localization is essential. By default Pedro Pathing supports: **Pinpoint**, **Dead-Wheels**, **OctoQuad** and **OTOS**. Any form of localization would work if you implement a custom localizer for it. 

### Programming Platform

For Pedro Pathing you **must** use **Android Studio**. Pedro Pathing does not work with OnBot Java or Blocks.

Once you made sure you completed all of those you can [proceed to installation](/docs/pathing/installation).
