title: Constraints

**Constraints** and **tuning parameters** control two related things: when a path segment (and the overall path) is considered **finished** or settled, and how the `follower` balances **heading, position, and speed** corrections while actively driving. All of these are configured in `ForesightConfig`.

### Parametric T

`parametricTConstraint` determines how close the closest t-value must be to `1` before the path reaches its parametric end.

The default value is `0.025`, meaning the closest t-value must reach at least `0.975`.

```java
c.parametricTConstraint.set(0.025);
```

Increasing this value allows the path to reach its parametric end earlier, while decreasing it requires the robot to get closer to `t = 1`.

### Velocity

`velocityConstraint` sets the velocity threshold used while correcting at the final Pose.

The default value is `0.1`.

```java
c.velocityConstraint.set(0.1);
```

The velocity along the correction direction must be below this value for the velocity constraint to be met.

### Translational

`translationalConstraint` sets the maximum allowed distance between the robot and the final target position.

The default value is `0.1`.

```java
c.translationalConstraint.set(0.1);
```

The translational error must be below this value for the translational constraint to be met.

### Heading

`headingConstraint` sets the maximum allowed heading error between the robot and the final target heading.

The value is in radians, and the default is `0.007`.

```java
c.headingConstraint.set(0.007);
```

`Math.toRadians()` can also be used when setting the value:

```java
c.headingConstraint.set(Math.toRadians(1));
```

The heading error must be below this value for the heading constraint to be met.

### Timeout

`timeoutConstraint` sets how long, in milliseconds, the follower is allowed to correct at the final Pose before the timeout constraint is met.

The default value is `100` milliseconds.

```java
c.timeoutConstraint.set(100.0);
```

Increasing the timeout gives the robot more time to correct at the endpoint. Decreasing it allows the follower to finish sooner if the other endpoint constraints cannot be met.

### Heading Drive Ratio

`headingDriveRatio` controls how much priority is given to heading correction compared to forward movement. Higher values give heading correction more priority, while lower values allow more forward movement before heading correction takes priority.

The default value is  `0.5`.

```java
c.headingDriveRatio.set(0.5);
```

### Path Continuation

`brakeAtEnd` determines whether the robot should start braking before getting to the end of the path or keep coasting.
This only affects the final location, the rest of the paths continue normally.

The default value is `true`.

```java
c.brakeAtEnd.set(true);
```

### Deviation Tolerances

`translationalDeviationTolerance` and `headingDeviationTolerance` determine whether the robot's position and heading are still on track. If either error exceeds its tolerance, the follower prioritizes correcting the error instead of continuing normally along the path.

The default value for `translationalDeviationTolerance` is `2.5`, And for  `headingDeviationTolerance` is `11.25` degrees.

```java
c.translationalDeviationTolerance.set(2.5);

c.headingDeviationTolerance.set(Math.toRadians(11.25));
```

### Cosine scaling

`cosineScale` reduces the robot's forward speed when its position or heading error gets too large.

Once the error passes twice the deviation tolerance, forward speed drops to zero, giving the correction controllers full use of the remaining power. It doesn't make the correction stronger; it just reduces the competition from forward movement. Below the tolerance, forward speed stays unchanged.

The default value is `false`.

```java
c.cosineScale.set(true);
```

### Setting Constraints

Constraints can be changed in `ForesightConfig` alongside the other follower constants:

```java
public static ForesightConfig foresightConfig = new ForesightConfig(
    c -> {
        c.parametricTConstraint.set(0.025);
        c.velocityConstraint.set(0.1);
        c.translationalConstraint.set(0.1);
        c.headingConstraint.set(0.007);
        c.timeoutConstraint.set(100.0);

        c.headingDriveRatio.set(0.5);
        c.brakeAtEnd.set(true);
        c.translationalDeviationTolerance.set(2.5);
        c.headingDeviationTolerance.set(Math.toRadians(11.25));
        c.cosineScale.set(true);


        // Other Foresight constants...
    }
);
```

### Path Completion

During path following, the current path reaches its parametric end when `parametricTConstraint` is met.

At the final endpoint, when endpoint holding is enabled, the follower corrects toward the final Pose. `follower.isBusy()` becomes false when the velocity, translational, and heading constraints are all met, or when the timeout is reached.

<Callout title="Tip" type="info">
    If the follower takes too long to finish at the endpoint, check the final position, heading, and velocity errors before changing the constraints. Increasing `parametricTConstraint` reaches the parametric end earlier, while decreasing `timeoutConstraint` reduces how long the follower continues correcting at the end.
</Callout>
